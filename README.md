# 📝 Todos App

A simple and responsive Todo application built using React and Node.js.

---

## 🚀 Features

- Add new todos
- Delete todos
- Mark as completed
- Responsive UI
- Clean and modern design

---

## 🛠 Tech Stack

**Frontend:**
- React
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/harinim214/Todos-
cd todos-app
```

### 2️⃣ Install Dependencies

Backend:
```bash
cd server
npm install
```

Frontend:
```bash
cd client
npm install
```

### 3️⃣ Run the Application

Backend:
```bash
npm start
```

Frontend:
```bash
npm run dev
```
