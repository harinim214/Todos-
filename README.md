# 📝 Todos App

A simple and responsive Todo application built using React and Node.js.

---

## 🚀 Features

- Add new todos
- Delete todos
- Mark as completed
- Responsive UI
- Clean and modern design

---

## 🛠 Tech Stack

**Frontend:**
- React
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB
